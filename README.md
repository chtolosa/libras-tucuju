# Libras Tucuju

Site demonstrativo em HTML, CSS e JavaScript.

## Executar localmente
Abra `index.html` em um navegador moderno ou publique os arquivos no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Em Settings > Pages, selecione Deploy from a branch, escolha `main` e `/ (root)`.
4. Aguarde a URL ser publicada.

## Importante sobre dados e segurança
Esta versão salva dados no navegador (localStorage). Contas, PINs, moderação, fórum e arquivos não são compartilhados entre dispositivos nem constituem autenticação segura. A senha de coordenação está como `TROQUE-ESTA-SENHA-ANTES-DE-PUBLICAR` dentro do JavaScript: altere-a antes de testar, mas saiba que qualquer senha no front-end pode ser vista no código-fonte. Para uso público real, é necessário backend com autenticação, banco de dados, armazenamento de mídia e controle de permissões no servidor. A validação de professores deve ser feita por pessoas responsáveis e com conferência documental.
